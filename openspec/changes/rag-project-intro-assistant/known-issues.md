# RAG 项目介绍助手 已知问题记录

> 来源: M3 召回+remark+边界 联调/质检发现。**对接完成后统一修改**,不在当前切片逐个处理。
> 归属: 多为 Python/Model 侧(语料与切片),Java 侧仅 source 代理路径受牵连。

---

## 问题 1:切片未完全按面试官提问切分 / 打标不完善

- **发现于**: M3 召回+remark+边界(真实召回质量检查)
- **现象**: 切片数据(`docs/rag/ai-tutoring/切片数据/**`)没有**完全按照面试官可能的提问方式来切**,或 `tags.module` / `locked_sections` 等**打标没打好**
- **影响**: 影响召回命中率与 RRF 重排质量——部分面试官式问题召回不到最优块,或 rerank 命中权重不对
- **归属**: Python/Model 侧(切片与打标逻辑:`slice_corpus.py` / 切片清单)
- **修复时机**: 三端对接完成后统一修改(可能需重跑切片 + 重跑评估 baseline)

## 问题 2:文档地址不对,后续统一到 COS

- **发现于**: M3 查看原文(source 代理)联调
- **现象**: rerank 块的 `file_path` 很多指向的地址不对(依赖本地/相对路径),前端"查看原文"可能打不开或指向错误文档
- **影响**: 引用面板"查看原文"体验断裂
- **归属**: Python/Model 侧(语料地址统一迁移到 COS 存储);Java 侧 source 代理(`GET /api/rag/assistant/source?path=`)随 file_path 格式变化可能需要小适配
- **修复时机**: 三端对接完成后统一迁移到 COS,并同步更新 `file_path` 字段的地址格式

## 问题 3:缺少流程图

- **现象**: 语料/回答缺少流程图(流程类回答只有文字,没有 mermaid/图示辅助),面试官问"流程怎么走"时只能看文字、不易理解
- **影响**: 流程类问题(如 AI答疑完整流程、架构拓扑)回答表达力弱
- **归属**: Python/Model 侧(语料补充流程图内容;原设计 Non-Goal"不实现 mermaid 动态生成",可考虑语料预置流程图文本,渲染另议)
- **修复时机**: 对接完成后统一补充语料流程图内容

## 问题 4:功能使用内容缺失

- **现象**: 语料缺少"功能使用/操作"类内容——怎么操作各个功能(入口、步骤、结果),操作类问题召回不到对应块
- **影响**: "XXX 怎么用"类问题答不出/答偏
- **归属**: Python/Model 侧(语料补充功能使用/操作类切片,对齐引导方向②操作)
- **修复时机**: 对接完成后统一补充功能使用类语料

## 问题 5:文档引用需放到最后

- **现象**: 回答中的文档引用(查看原文/引用块)当前展示位置不理想,需要统一放到**答案最后**(而非中间打断正文)
- **影响**: 回答正文被引用打断、观感散;应正文完整,引用集中尾部
- **归属**: Python 侧(回答格式/generate prompt 引用位置约束)+ 前端侧(引用面板展示位置,底部聚合)
- **修复时机**: 对接完成后统一调整引用展示位置到答案尾部

## 问题 6:引导建议太随机、很多不可答

- **现象**: 回答完成后的引导建议(结束建议/done.suggestions)由 LLM 随机生成,很多问题在语料里**没有对应内容**,学生点进去答不上/答偏
- **影响**: 引导点击后无答案,体验断裂;引导价值丧失(本应带学生到 ①②③④ 高频方向)
- **期望**: AI 先**列举 50 个高频问题**作为引导底座(对齐语料,保证每个都能答),随机生成时**从这 50 题池子里抽**(而非纯 LLM 自由发挥);开始引导 guide 静态池同理对齐
- **归属**: Python 侧(建议生成逻辑 + 50 题底座池 + 与语料对齐)+ 语料侧(保证 50 题都有对应切片)
- **修复时机**: 对接完成后统一建立 50 题高频底座池并校准可答性
