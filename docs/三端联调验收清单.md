## 一、RAG 助手（前端 F-M1~F-M8，联调收尾）

契约：`POST /api/rag/assistant/ask`(SSE) 事件序 `permission→intent→(clarify|switch)→rewrite→rerank→(boundary|token*)→done`；
`GET /guide` ｜ `GET /source` ｜ `POST /sessions/{id}/close` ｜ `GET /turns/{traceId}` ｜ `GET /eval/report` ｜ `POST /eval/run`

- [ ] **RAG-A-01 角色门**：学生进页正常提问；教师/未登录 → 固定 403（不进 RAG 流程、无 token）。 [✅后端 RAG-GATE-001~004 已绿]
- [ ] **RAG-A-02 开始引导**：进页出现引导 chips（1~3 条，必含 ≥1 条 RAG 方向）；点击 chips → 发起对应问题。 [🔶 后端 guide 已测 / 前端 GuideChips 已实现]
- [ ] **RAG-A-03 SSE 时序**：提问 → 按序收到 permission(traceId)→intent(anchor+category)→rewrite(改写前后)→rerank(引用块)→token*→done(answer+quotedKeys+tokensUsage+traceId+suggestions)，前端按序渲染、无缺漏。 [✅ 后端 RAG-SSE-001 联调套件已测]
- [ ] **RAG-A-04 流式渲染+成本**：答案逐字输出不断流；成本面板显示 prompt/completion/cache_hit/total 四字段。 [✅ 后端 RAG-COST-001 已测]
- [ ] **RAG-A-05 引用高亮**：rerank 块先灰显；done 后 quotedKeys 命中块高亮、未命中灰显折叠。 [🔶 前端 F-M5 已实现]
- [ ] **RAG-A-06 查看原文**：点击引用块 → 走 Java `source` 代理返回原文（CORS/中文路径/COS key 正常）。 [✅ 后端 source 代理已测，含跨模块 COS key]
- [ ] **RAG-A-07 边界拒答**：语料外问题 → boundary 事件 +「未找到关联文档，我尚未掌握。」0 token，前端展示拒答态。 [✅ 后端已测]
- [ ] **RAG-A-08 澄清**：歧义问题（候选≥2）→ clarify 卡片（candidates+default），点选=重发原问+currentProject；最多澄清一轮。 [✅ Python 已测 test_assistant_clarify / 🔶 前端 ClarifyCard 已实现]
- [ ] **RAG-A-09 上下文切换**：currentProject 变化 → switch 事件(fromAnchor/toAnchor)，按新锚点继续。 [✅ 后端已测]
- [ ] **RAG-A-10 追问展开**：省略主语追问（带 history 最近 3 轮）→ 命中原模块不跳走。 [✅ 后端 history 透传已测，联调套件覆盖]
- [ ] **RAG-A-11 问候轮**：「你好」等 → 欢迎语+模块引导建议，0 token。 [✅ 后端已测]
- [ ] **RAG-A-12 四模块**：currentProject 取 4 模块（ai-tutoring/knowledge-graph/question-analysis/rag-system）各能提问，引用块 file_path 全来自对应模块（0 泄漏）。 [✅ Java 多模块联调套件 4 用例已测]
- [ ] **RAG-A-13 结束引导**：done.suggestions 结束建议 chips（池内原题，可答），点选再问。 [✅ 后端已测]
- [ ] **RAG-A-14 会话结算**：关闭对话 → `POST /sessions/{id}/close` → 返回累计 token+轮数；已关闭后再问 → 固定话术「本轮对话已结束，可开启新对话。」0 token。 [✅ 后端 M7 已测]
- [ ] **RAG-A-15 断线补查**：SSE 断线后凭 trace_id → `GET /turns/{traceId}` 找回该轮完整回答。 [✅ 后端 M7 已测]
- [ ] **RAG-A-16 评估报告**：评估报告一屏（hit@3/质量分/成本/耗时/真实对话区段）；「重新评测」→ `POST /eval/run` → 轮询 running → 刷新。 [✅ 后端 eval/report+run 已测]
- [ ] **RAG-A-17 非流式 ask/sync**：`POST /ask/sync` → 真实 answer+stages 摘要（Python stream=false，snake→camel）。 **✅ 后端已接真实（2026-08-29，Bridge+AppService+联调套件 11 用例含真实非流式）；前端 `ask()` 改打 `/ask/sync` 即可联调。**
